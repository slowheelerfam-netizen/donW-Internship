# Ultraverse NFT Marketplace

A React-based NFT marketplace frontend built as part of a frontend development internship project.

🔗 **Live Demo:** https://donW-Internship.vercel.app

## Features

- Browse NFT collections with live countdown timers on expiring items
- Explore page with filterable NFT listings
- Author/creator profile pages
- Item detail pages
- Skeleton loading states for better UX
- AOS scroll animations throughout
- Fully responsive design

## Tech Stack

- React (Create React App)
- React Router DOM
- Bootstrap 5
- Font Awesome icons
- AOS (Animate On Scroll)

## Pages

| Page | Route |
|------|-------|
| Home | `/` |
| Explore | `/explore` |
| Author | `/author/:id` |
| Item Details | `/item-details/:id` |

## Getting Started
```bash
npm install
npm start
```
